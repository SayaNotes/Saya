## Saya

**Saya — Some things are beautiful simply because they stay. ❤️**

Saya is designed to make capturing ideas feel calm and effortless. It brings handwritten notes, PDF work, sketches, folders and a flexible canvas into one focused workspace.

## Highlights

- A custom home experience for recent work, pinned notes and folders.
- Handwriting, drawing, shapes and an infinite canvas.
- PDF import, viewing, annotation and export.
- Search, organisation, previews and flexible layouts.
- Customisable tools, themes and workspace preferences.
